# Readhand-UI

Redhand-ui is a (work in progress) stand alone UI library which extends [Tailwind](https://tailwindcss.com/) css.

If you wish to have access to the Figma files contact [graham.clapham@101ways.com](mailto:graham.clapham@101ways.com).

Design Tokens, generated by [Token Studio for Figma](https://tokens.studio/), are pushed to **rh_tokens/tokens.json**. Running ```yarn token``` will generate a set of Design Tokens compatible with Css Modules, StyleX, SCSS and TypeScript in the folder **design_token_exports**.

Theming is based on [Design Tokens](https://design-tokens.github.io/community-group/format/) generated from [Figma](https://www.figma.com/design/FHiQECKXdsHnzLODCg5uyT/Dialect-%E2%80%93-Design-System-%26-Component-Library-(Free)-(Community)-(Copy)?node-id=0-1&t=D9QqAdXvkrVnPXKY-0) 

Storybook has been incorporated to allow Component Driven Development. Run:```yarn storybook``` to launch it.

Any Components added to the library should be exposed by exporting them from **index.ts**

The testing framework is Jest – run:```yarn test``` to run tests.

The library is published to Graham Clapham’s personal NPM registry. To publish increase the version number in package.json and run ```npm publish``` – 2FA is required to publish.

## Using Redhand-ui in a project


insall the package

```bash
npm install redhand-ui
```
To use in a project the project will need to have Tailwind installed.

```bash
npm install -D tailwindcss
npx tailwindcss init
```

At the root of the project create a **tailwind.config.js** file 

_tailwind.config.js_

```javascript
import redhandPlugin from "redhand-ui/tw-plugins/redhand-plugin";
import redhandThemeCss  from "redhand-ui/tailwindConfig/tailwind.theme.light.config";

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./src/**/*.{js,jsx,ts,tsx}",
  ],
  theme: {
    extend: {
        ...redhandThemeCss
    },
  },
  plugins: [redhandPlugin],
}
```

In 'src' create **input.css**.

_input.css_

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

run the following in the terminal (it's wise to add this to the 'scripts' section of package.json)

```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```
This will create a CSS file  at ```./src/output.css ``` which will need importing into the Head of the **index.html** file
```html
    <link href="./src/output.css" rel="stylesheet">
```
Now components may be imported into the project and used as shown below. 

```javascript
import { ButtonTw } from 'redhand-ui'
```

The Components are built in React 18, however, as Tailwind is pure CSS, the styles may be used with any framework or vanilla HTML.
